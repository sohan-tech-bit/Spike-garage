# Spike Garage

Spray-paint and sticker a car in a real horror garage. Built for **Kiroween 2026** (Costume Contest) with Kiro.

> Live demo: _add URL_ | Demo video: _add YouTube URL_

## What it does
- Walk into a fog-filled, flickering haunted garage in 3D
- Pick a car (generic invented names, no brand logos)
- Spray-paint directly on the car: color, size, opacity, softness, plus rust, blood drip, cobweb and glow sprays
- Place, scale, rotate and layer original horror stickers
- Undo/redo, clear, save a PNG

## Run locally
```bash
npm install
npm run dev
```
